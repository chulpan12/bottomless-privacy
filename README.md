# 바텀리스 개인정보처리방침

안드로이드 게임 **바텀리스 (The Bottomless)** — `com.tinbird.abyssdungeon` 의
개인정보처리방침을 공개 URL 로 두기 위한 저장소다.

공개 주소: <https://chulpan12.github.io/bottomless-privacy/>

이 주소를 Play Console 의 `앱 콘텐츠 → 개인정보처리방침` 에 넣는다.

방침을 고칠 때는 `index.html`(한국어·영어가 한 쪽에 같이 있다)을 고치고
`PRIVACY.md`(게임 저장소의 원본 사본)도 함께 맞춘다.
